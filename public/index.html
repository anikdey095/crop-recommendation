How to Deploy to Vercel

Zero-config serverless deployment instructions
  1. Push to GitHub: Commit and push the project to your GitHub repository.
  2. Import to Vercel: Go to vercel.com/new and select your repository.
  3. Zero Configuration Needed: The preconfigured vercel.json, api/index.py, and requirements.txt automatically handle the serverless function routing and static asset CDN.
  4. Click Deploy: In ~60 seconds, your production URL will be live with instant global edge caching!
🚀 Dual-Engine Serverless Guarantee:

The API uses a dual-engine architecture: primary scikit-learn model with an instant pure-Python JSON tree evaluator fallback. This ensures 0% cold start downtime and 100% uptime on Vercel's serverless tier.

🔌

POST /api/predict

Send soil & climate parameters, receive crop advisory
Example Request (cURL): 
curl -X POST "https://your-app.vercel.app/api/predict" \
  -H "Content-Type: application/json" \
  -d '{
    "N": 90,
    "P": 42,
    "K": 43,
    "temperature": 24.5,
    "humidity": 82.0,
    "ph": 6.5,
    "rainfall": 202.9
  }'
Python (requests): 
import requests

res = requests.post("https://your-app.vercel.app/api/predict", json={
    "N": 90, "P": 42, "K": 43,
    "temperature": 24.5, "humidity": 82.0,
    "ph": 6.5, "rainfall": 202.9
})
data = res.json()
print("Recommended Crop:", data['prediction']['name'])
print("Confidence:", data['prediction']['confidence'], "%")
